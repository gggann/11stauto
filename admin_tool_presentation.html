2. UI/UX: 메인 레이아웃

Layout Structure

  • Header: 검색(포함/제외), 상태 필터 탭
  • Grid: 썸네일, 상품명, 카테고리 정보
  • Highlight: 일치(초록) / 불일치(빨강) 시각화
전체 레이아웃 스크린샷

3.1 고급 필터링 & 검색

  • OR/AND 검색: 쉼표(,)로 다중 조건 검색
    (예: 운동화, 나이키 → 모두 포함)
  • 제외 검색: 마이너스(-)로 불필요 항목 제거
    (예: -아동, -리퍼)
  • 상태 필터: 미처리 / 처리완료 탭 분리
필터링/검색 동작 예시 이미지

3.2 스마트 입력 & Hover UI

Hover Interaction

  • 평소: 입력창 숨김/간소화 (복잡도 ↓)
  • 마우스 오버: 입력창 활성화 (display: block)
  • 자동 완성: 2-depth 필터 칩 추천
Hover 전/후 비교 이미지

3.3 키워드 상호작용 (Click-to-Fill)

  • One-Click 입력:
    하이라이트된 키워드 클릭 시 '수정 카테고리'에 자동 입력
  • Toggle 기능:
    재클릭 시 입력 취소
  • 안전장치:
    성별(남/여) 등 민감 키워드는 클릭 제한
키워드 클릭 동작 예시 이미지

3.4 성별/연령대 정합성 검사

1. 성별 충돌 감지: 상품명 '남성' ↔ 카테고리 '여성' [경고]

2. 연령 충돌 감지: 성인용품 ↔ '키즈/유아' 카테고리 [경고]

3. 예외 허용: '남녀공용', '패밀리룩' 등은 안전하게 허용

정합성 검사 경고 팝업/UI 예시

3.5 대량 작업 & 일괄 업데이트

  • 일괄 적용: 선택된 상품들에 동일 카테고리 적용
  • 클립보드 복사: 엑셀 호환 포맷 지원
  • Batch Verification Update:
    검수 완료된 전체 상품을 한 번에 서버로 전송/저장
    ('저장' 버튼 원클릭으로 일괄 처리)

Pagination

  • 페이지당 100개 노출 (성능 최적화)
