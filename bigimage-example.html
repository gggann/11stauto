🔍 BigImage 모듈 사용 예시

1. 기본 사용법

이미지에 마우스를 올리면 확대 버튼이 나타납니다. 클릭하여 이미지를 확대해보세요.

2. 버튼으로 직접 호출

3. 사용법

// 1. 모듈 import import { BigImageModule } from './bigimage.js'; // 2. 이미지 확대 모달 표시 BigImageModule.showImageModal('이미지URL'); // 3. 확대 버튼 생성 (자동으로 이벤트 연결됨) const zoomBtn = BigImageModule.createZoomButton('이미지URL', { position: 'bottom-right', // 'top-right', 'bottom-left', 'top-left' icon: '🔍', title: '이미지 확대' }); // 4. Vue 컴포넌트에서 사용 const vueMixin = BigImageModule.getVueMixin(); // 컴포넌트에 믹스인 추가 후 this.showImageModal() 사용 가능

4. 주요 기능

  • ✅ 이미지 확대 모달 표시/숨기기
  • ✅ ESC 키로 모달 닫기
  • ✅ 모달 배경 클릭으로 닫기
  • ✅ 확대 버튼 자동 생성
  • ✅ Vue.js 믹스인 제공
  • ✅ 반응형 디자인 (모바일 지원)
  • ✅ 이미지 로드 에러 처리
  • ✅ 스크롤 방지/복원
