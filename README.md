# 11st Auto — 검색카테고리 정합성 검수 도구

11번가 이커머스 플랫폼의 상품 검색카테고리 정합성 검수 및 수정 작업을 위한 웹 기반 작업자 도구입니다. 다수의 작업자가 동시에 대량의 상품을 효율적으로 검수할 수 있도록 설계되었습니다.

---

## 🛠 기술 스택

| 계층 | 기술 |
|---|---|
| **프론트엔드** | Vue.js 2, Bootstrap 5, jQuery 3.6, Toastify.js |
| **HTTP 클라이언트** | Axios |
| **백엔드 API** | Express.js (Node.js) — 포트 3100 |
| **데이터베이스** | PostgreSQL + PostgREST — 포트 3933 |
| **클라우드 스토리지** | Supabase |
| **웹 서버** | Nginx 1.20.2 (정적 리소스 서빙) |
| **기타** | MSSQL (QC 연동), 로컬 이미지 서버 |

---

## ✨ 주요 기능

### 📋 작업 배분 시스템
- 작업자 이름 입력 시 PostgreSQL에서 미처리 상품 자동 배분 (20/30/50/100건 단위)
- `FOR UPDATE SKIP LOCKED` 기반 동시성 제어로 중복 배분 방지
- 1시간 타임아웃 초과 시 자동 릴리즈
- 작업 완료 제출 후 자동 재배분

### 🏷 상품 카테고리 검수
- 11번가 검색 API 연동으로 상품 정보 실시간 조회
- 카드 형태 UI로 상품 이미지, 상품명, 가격, 셀러, 카테고리 등 표시
- 수정카테고리 입력 필드 제공

### 🔍 카테고리 검증 & 추천
- **유효 카테고리 화이트리스트** (~9,600개) 기반 0ms 자동완성
- **키워드 추천**: 상품명에서 키워드 추출 → 매칭 카테고리 추천
- **성별/연령대 검증**: 남성 상품이 여성 카테고리에 매칭된 경우 자동 경고
- 다중 키워드 AND 조건 검색, 2뎁스 필터 칩 지원

### 🎨 키워드 하이라이트
- 상품명과 카테고리 간 키워드 매칭을 색상으로 시각화
  - 🔵 파란색: 상위 depth 키워드 일치
  - 🔴 빨간색: 리프(최하위) 카테고리 키워드 일치
  - **굵은 테두리**: 특수 키워드 (남성/여성/아동 등) 강조
- 키워드 클릭 시 수정카테고리 자동 입력 (Click-to-Fill)

### ✅ 다중 선택 & 일괄 처리
- 체크박스 기반 다중 선택
- 키워드 필터링으로 특정 상품군 일괄 선택 (포함/제외 검색)
- 선택 상품에 카테고리 일괄 적용

### ⌨️ 뷰 모드 단축키
| 단축키 | 기능 |

| `F6` | 이미지만 보기 |

| `F8` | 검색카테고리 + 수정카테고리 |

### 💾 자동 저장 & 통계
- 30초 간격 localStorage 자동 저장 (브라우저 종료 시 복원)
- 작업자별 일일 작업량 통계 대시보드 (`total.html`)
- 남은 상품 수 및 오늘 제출 수 실시간 표시

### 🛠 편의 기능
- 네이버 쇼핑 검색 (상품명 기반)
- 클립보드 복사 (HTTP/HTTPS 자동 감지)
- 수정카테고리 엑셀용 복사
- 이미지 확대 모달 (로컬 이미지 우선, CDN 폴백)
- 폰트/이미지 크기 동적 조절

## 🗄 데이터베이스

PostgreSQL의 `ordermod` 테이블이 핵심입니다:

| 컬럼 | 설명 |
|---|---|
| `ID` | 기본키 |
| `prd_no` | 상품번호 |
| `prd_nm` | 상품명 |
| `search_category` | 검색카테고리 |
| `corrected_category` | 수정카테고리 |
| `worker_name` | 작업자명 |
| `assigned_to` | 배분받은 작업자 |
| `assigned_at` | 배분 시각 |
| `submitted_at` | 제출 시각 |

**RPC 함수**: `assign_tasks`, `submit_tasks`, `get_free_count`, `get_today_submitted_count`, `get_daily_stats`, `get_statistics`

## 🔄 작업 흐름

1. 작업자가 이름 입력 후 상품 배분 요청 (20~100건 선택)
2. PostgREST RPC로 미처리 상품 자동 할당
3. 각 상품 카드에 상품 정보 로드 (11번가 API)
4. 키워드 하이라이트, 카테고리 추천, 성별 검증 자동 실행
5. 작업자가 수정카테고리 입력 (자동완성, 툴팁, 클릭입력 활용)
6. 다중 선택/일괄 적용으로 효율적 작업
7. **"작업 제출"** 클릭 시 DB에 결과 저장
8. 자동으로 새 작업 재배분 (순환 작업)

## 🚀 실행 방법

### 1. Nginx 설정

Nginx의 정적 리소스 디렉토리에 프로젝트를 배치합니다:

```nginx
server {
    listen 80;
    root /path/to/11stauto;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### 2. 백엔드 API 서버 실행

```bash
node api.js
# 포트 3100에서 실행
```

### 3. PostgREST 설정

PostgREST를 포트 3933에서 PostgreSQL 데이터베이스에 연결하여 실행합니다.

### 4. 접속

브라우저에서 Nginx 서버 주소로 접속합니다.
