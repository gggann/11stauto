# 变更说明

## 主要改动概览

1. **关键词工具统一调用**
   - 删除 `tt.js` 内部重复的关键词解析/筛选函数，统一调用 `KeywordProcessor` 静态方法。
   - 调整 `keyword.js` 静态方法也使用 `KeywordProcessor.*` 互调，避免 `this` 丢失导致报错。
2. **Tooltip 重构**
   - 原先在模板中渲染 tooltip；现改为点击后使用 `renderTooltip`/`createBodyTooltip` 重新生成 DOM 并挂载到 `body`。
   - 重新启用 `generateTooltipHTML`、`removeAllTooltips` 并手动绑定关闭、重置、鼠标悬停及搜索输入等事件，确保与旧版本一致的交互。
   - `applyCategorySearch`、`applyKeywordFiltering` 在状态变化时会重绘 tooltip；`hideKeywordTooltip`/`beforeDestroy` 负责清理残余节点。
3. **父子通信与展示开关**
   - 新增 `uiFlags` 计算属性，所有模板条件都转为 `uiFlags.*`；降低 `$parent.*` 直接耦合。
   - 增加 `shouldShowCategoryRecommendation` 并在 watcher 中使用，统一控制推荐功能显隐。
4. **关键词高亮事件管理**
   - `attachKeywordEvents` 先调用 `detachKeywordEvents`，并记录 `_clickHandler` 等引用以便解绑。
   - `beforeDestroy` 增加 `removeAllTooltips()`，确保组件销毁时清理 tooltip 节点。
5. **搜索与筛选行为**
   - 引入 `categorySearchInput` 保存输入框状态，`applyCategorySearch`、`resetFiltersAndHideTooltip` 同步更新并立即重绘 tooltip。
   - 点击 “重置” 或隐藏 tooltip 时会清空输入框并刷新推荐列表。
6. **日志与调试信息**
   - 保留核心调试 log（如分类验证、关键词测试），其余根据需要可自行删减。
